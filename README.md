# C 盘瘦身助手（migrate）

一个面向 Windows 的保守型 C 盘扫描、软件数据迁移、卸载、安全清理与报告脚本。

当前版本：**v1.2**

## 功能

- 只读扫描 C 盘主要占用与 AppData 大目录。
- 将指定软件数据迁移到 D 盘，并通过 Junction 保持原路径可用。
- 识别已经迁移的 Junction / 软链接，避免重复迁移。
- 从系统卸载列表启动第三方软件卸载程序。
- 保守清理用户/系统临时文件、缩略图、浏览器缓存与着色器缓存。
- 生成本次会话的 C 盘净释放 / 净新增占用报告。
- 对迁移后保留的 `.old` 备份进行人工确认后的删除或回滚。

## 使用方法

1. 下载 `C_Disk_Slim_Helper_v1.2.ps1` 和 `C_Disk_Slim_Helper_v1.2.bat`，放在同一文件夹。
2. 双击 `C_Disk_Slim_Helper_v1.2.bat`。
3. 脚本需要时会请求管理员权限。
4. 建议先运行 `[1] 扫描C盘（只读）`，确认结果后再决定是否执行修改操作。

## 安全设计

- 默认扫描是只读操作。
- 迁移、卸载、清理、删除 `.old` 备份都需要人工确认。
- 迁移流程采用“复制 → 校验 → 原目录改名为 `.old` → 建立 Junction”。
- Junction 创建失败时会尝试自动恢复原目录。
- 迁移成功后不会自动删除 `.old`，应先实际打开软件验证，再通过 `[6]` 输入 `DELETE` 完成收尾。
- `.old` 仍存在时，可通过 `[6]` 输入 `ROLLBACK` 恢复到 C 盘原目录。
- 默认安全清理明确保留 Windows Logs、WER、CrashDumps、`C:\Windows\Minidump`，也不会自动清理 Windows Update 下载缓存。

## 测试状态

v1.2 已在一台 Windows 机器上完成以下验收：只读扫描、已迁移 Junction 识别、重复迁移拦截、卸载列表、清理取消流程、报告、迁移收尾/回滚检测，以及 `[0]` 真正退出。

**尚未完成完整的破坏性端到端测试**，包括在独立测试环境中的“全新真实迁移 → DELETE 删除 `.old` → ROLLBACK”等完整链路。首次真实迁移时，请优先选择非关键软件，并提前备份重要数据。

## 重要提醒

这个脚本会涉及文件移动、Junction、卸载程序和缓存清理。请先阅读脚本、确认目标路径，并备份重要数据。不要把“通过当前验收”理解成对所有 Windows 环境的绝对安全保证。
